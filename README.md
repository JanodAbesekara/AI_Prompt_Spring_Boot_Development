# Article Management System

A Spring Boot REST API project for managing articles.

---

# Features

- User Authentication
- JWT Security
- Create Articles
- Update Articles
- Delete Articles
- Get All Articles
- MySQL Database
- Docker Support

---

# Technologies

- Java 17
- Spring Boot 4
- Spring Security
- Spring Data JPA
- MySQL
- Maven
- Docker

---

# Run Project

## Build

```bash
mvn clean package
```
## Run

```bash
java -jar target/article-management-0.0.1-SNAPSHOT.jar
```

---

# API Base URL

```text
http://localhost:8080/api
```
